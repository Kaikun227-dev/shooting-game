# shooting-game
PC上で動作するシューティングゲームの開発。個性的なアイテムや強力なボス、更には「呪字」とよばれる独自のパッシブ要素まで実装させる。


   STELLAR ROGUE — ローグライトシューティング 説明書
================================================================


■ ゲーム概要
----------------------------------------------------------------
STELLAR ROGUE（ステラローグ）は、PC（ブラウザ）で遊べる
ローグライトシューティングゲームです。

プレイヤーは凸形の宇宙船を操り、押し寄せる雑魚敵の群れを生き延び、
アイテムと「呪字」を集めながら自機を強化して、ボスを撃破することを
目指します。

毎回のプレイ開始前にアイテムを選び、自機をカスタマイズするのが
このゲームの醍醐味です。ランダム要素が多く、何度遊んでも
異なる体験が楽しめます。


■ ゲームの3つのモード
================================================================

◆ NORMAL MODE（通常モード）
------------------------------------------------------------
タイトル画面の「START GAME」を選択すると開始します。

ゲーム開始前に「初期アイテム選択」が行われます。
4個ずつ表示されるアイテムから合計6個を選んでスタート。

ゲームの流れは以下の通りです：

  WAVE 1（雑魚敵フェーズ）
     ↓  クリア後 アイテム選択（3個）
  WAVE 2（雑魚敵フェーズ）
     ↓  クリア後 アイテム選択（3個）
  WAVE 3（雑魚敵フェーズ）
     ↓  クリア後 アイテム選択（3個）
  BOSS（ボスフェーズ）
     ↓  撃破後
  STAGE CLEAR！ → 周回プレイ（続けてプレイ）が可能

ボスを撃破すると「続けてプレイ」が選べます。
周回するごとに敵のHPが増加し、難易度が上昇します。
また2周目以降はWAVE中にイベントが発生するようになります。

また、呪字アイテムによってはWAVE間に呪字選択画面や
アイテム放棄画面が挿入されることがあります。


◆ BOSS RUSH MODE（ボスラッシュモード）
------------------------------------------------------------
タイトル画面の「BOSS RUSH」を選択すると開始します。

ボスを18体の中から1体選び、アイテムを15個選んだあとで
即座にそのボスと対戦するモードです。

強化された状態で好きなボスに単独挑戦できます。
倒せなかった場合は「再挑戦」で同じボスに再挑戦できます。


◆ SIMULATION MODE（シミュレーションモード）
------------------------------------------------------------
タイトル画面の「SIMULATION MODE」を選択すると開始します。

固定されたシナリオ（初期アイテム・呪字・フェーズ構成が決まっている）
に挑戦するモードです。シナリオは4種類あります：

  🌫️ 霧時々弾幕    — 霧と弾幕が交互に襲いかかる
  🌀 宇宙の災害    — ブラックホールと凶悪なボスが連続して迫る
  📈 インフレーション — 火力を極限まで高め超高HPの敵を粉砕せよ
  💀 堪え難き苦痛   — カルマで死を超えた先に何がある。極限の苦痛

各シナリオはフェーズが5つあり、ウェーブ・イベント・ボスが
固定順序で展開します。クリアすると専用のクリア画面が表示されます。


■ 操作方法
================================================================

  【移動】   WASD / 矢印キー
  【射撃】   スペースキー長押し
  【バリア】  Zキー（バリアアイテム取得後）
  【スーパーフラッシュ】 Aキー（スーパーフラッシュアイテム取得後）
  【ダッシュ】 Bキー（ダッシュアイテム取得後）
  【ファイア】 Vキー長押し（ファイアアイテム取得後）
  【脆弱弾】  Nキー（脆弱弾アイテム取得後）
  【ストックヒール】 Cキー（ストックヒールアイテム取得後）
  【一時停止】 Oキー

※ バリア・スーパーフラッシュ・ダッシュ・ファイア・脆弱弾は
　 対応するアイテムを取得しないと使用できません。


■ アイテム選択について
================================================================

WAVEクリア後やゲーム開始前に「アイテム選択」画面が表示されます。

・カードをクリックすると選択（黄色ハイライト）状態になります。
・選択後に「▶ 決　定」ボタンを押すと確定します。
・確定するまで何度でも選び直せます。
・「リロール」ボタンで選択肢を引き直せます（最初は0回、呪字で追加）。

呪字の種類によってはWAVEクリア後に「呪字選択」や
「アイテム放棄」フェーズが追加で挿入されます。

イベントをクリアした場合、次のアイテム選択ボーナス+1枚が
追加されます（通常3枚→4枚）。


■ 雑魚敵フェーズについて（WAVE 1〜3）
================================================================

各WAVEは30秒間続きます。
時間が経過すると自動的に敵が湧き出し、30秒後にはすべての敵が
消去されてWAVEクリアとなります。

◇ 敵の湧き方
  ・1秒（60フレーム）ごとに敵がスポーン。
  ・WAVE1は少なく、WAVE3は多め。
  ・2周目以降はさらに多くの敵が同時に出現。
  ・プラスヒール（回復の敵）も一定確率で出現。

◇ 中盤の精鋭出現（15秒時点）
  WAVEが15秒を過ぎると、強力な「精鋭敵」が追加で出現します。
  精鋭はランダムで以下の4種類から選ばれます：
    → ペンタゴン、オクタゴン、ヘックス、スター

  ただし「大量発生イベント」中は精鋭は出現しません。

◇ 当たり判定
  ・敵弾に当たるとHPが1減少します。
  ・レーザー、プラズマ、ハート形の敵の突進、これらのみ2ダメージです。
  ・ダメージを受けると無敵時間が発生します（約0.5秒）。
  ・HPが0になるとゲームオーバー（呪字「命」があれば1回復活）。

■ イベントフェーズについて
================================================================

通常モードの2周目以降（または特定の確率で）、WAVEとWAVEの
合間にイベントが発生することがあります。

イベントが発生した場合、次のWAVEが始まる前に「EVENT INCOMING」
の告知画面が表示され、何のイベントが起きるかが予告されます。

イベントWAVEを生き延びると、次のアイテム選択時に「ボーナス+1枚」
が追加で与えられます（通常3枚→4枚）。
また呪字「祝」を所持していると追加で呪字を1つ選択できます。

イベントは同じものが連続して起きないよう制御されています。

==================================================================

◆ EVENT 1 : 大量発生イベント（⚠）
------------------------------------------------------------------
  特定の敵種がWAVE中に大量に出現します。
  出現する敵の種類はランダムで以下12種から選ばれます：
    トライ、ダイヤモンド、スクエア、ヘックス、サイドトライ、
    レクト、サークル、プラス、ペンタゴン、オクタゴン、
    アロー、スター

  通常は様々な種類が混在して出現しますが、このイベント中は
  1種類の敵だけが延々と湧き続けます。
  また中盤（15秒時点）の精鋭出現がなくなります。

==================================================================

◆ EVENT 2 : 濃霧発生イベント（🌫）
------------------------------------------------------------------
  WAVE全体に白い霧がかかり、視界が悪化します。
  プレイヤーの周囲半径120px程度は見えますが、
  それ以外の画面が霧に覆われます。

  敵の位置が見えにくくなりますが、弾は見えます。

==================================================================

◆ EVENT 3 : 敵強化イベント（💢）
------------------------------------------------------------------
  WAVE中、すべての敵によるダメージが2倍になります。
  （体当たり・弾・レーザー等すべてに適用）

  回避を最優先に。バリアの使用タイミングが重要です。

==================================================================

◆ EVENT 4 : ハート出現イベント（💗）
------------------------------------------------------------------
  不死身の「ハート敵（ドロップレット）」が登場します。
  このハート敵はHPが実質無限で、倒すことができません。
  また体当たりダメージが2です。

  WAVE開始時に1体が出現し、15秒時点でもう1体追加されます。
  ハート敵は素早く突進してくるため、常に回避し続ける必要があります。

■ 呪字システム
================================================================

「呪字」は漢字1文字で表される特殊なアイテムです。
アイテムとは別のプールから選択でき、強力な効果を持つものが多い
一方で、デメリットを伴うものも存在します。

呪字選択は以下のタイミングで発生します：
  ・WAVE後に追加で呼び出される（特定の呪字取得後など）
  ・呪字「呪」「亀」「暗」「夢」などの効果で発生

呪字選択画面では「リロール」が可能です（呪字「再」で回数増加）。

◇ ゲームオーバー
  HPが0になるとゲームオーバー。
  （呪字「命」所持時は1回だけ最大HPで復活）
  リザルト画面から「もう一度挑戦」でリスタート（アイテムリセット）
  または「タイトルへ」で戻れます。

◇ ステージクリア（ボス撃破後）
  「続けてプレイ」を選ぶと周回プレイに入ります。
  HP3を回復した状態でWAVE1からやり直しになりますが、
  アイテムと呪字はすべて引き継がれます。
  周回数が増えるほど敵のHPが上昇し難易度が高まります。
  「タイトルへ」を選ぶとリセットされタイトルに戻ります。
